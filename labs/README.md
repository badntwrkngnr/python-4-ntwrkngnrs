# Labs

Hands-on material that goes beyond the written guides. Labs are grouped **by source**, so it stays clear where each exercise comes from.

| Lab | What it is | Level | Needs (from the guides) |
| :--- | :--- | :--- | :--- |
| [`how-network-devices-behave/`](how-network-devices-behave/) | Four small programs that simulate an Ethernet hub, an ARP cache, an Ethernet switch and an IP router | Intermediate | Guides 01–03, plus dictionaries, functions and classes (not covered in the guides yet) |
| [`leonardo-furtado/`](leonardo-furtado/) | Packets-and-Python exercises, from basic variables to a small OOP inventory manager | Beginner → Intermediate | Guide 01 for scripts `01` and `02`; classes and `match/case` for `05` |
| [`gustavo-kalau/`](gustavo-kalau/) | *Do CLI ao Código* series: containerlab topologies plus Netmiko scripts that configure them | Beginner → Intermediate | Guides 01–03, plus dictionaries and f-strings (not covered in the guides yet); Docker and containerlab |

> **Tip:** do the labs in the order listed inside each folder. They are numbered on purpose.
